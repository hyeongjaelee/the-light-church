03 · Desktop

데스크톱 화면

화면 구성은 노크처치를 따릅니다. 이번 주 설교 제목과 큰 영상으로 시작해 남색 Welcome 섹션, 예배 카드, 목사 소개, 주일학교 카드 순으로 이어집니다. 글꼴과 카드 스타일은 모바일과 같은 차분한 톤으로 맞췄습니다. 오른쪽 위 MENU를 누르면 모바일과 같은 커튼 메뉴가 데스크톱 크기로 열립니다.

05 · Tech

기술 구성

‘React’는 Next.js로 쓰는 것을 권장합니다. 주보나 설교 링크를 카카오톡으로 공유할 때 미리보기(제목, 썸네일)가 제대로 나오려면 서버 렌더링이 필요하기 때문입니다.

영역선택하는 일
프론트Next.js App Router + Tailwind페이지, 반응형 레이아웃, 카톡/네이버 미리보기(OG), 검색 노출
DBSupabase Postgres설교, 주보, 섬기는이들, 예배시간, 부서 정보
파일Supabase Storage주보 이미지/PDF, 교역자 사진
관리자Supabase Auth + /admin담당자가 주보를 드래그앤드롭으로 올리고, 유튜브 링크만 붙여 설교를 등록
배포Vercelgit push 하면 자동 배포, 수정마다 미리보기 링크 제공
웹앱PWA manifest홈 화면에 추가하면 앱처럼 전체화면으로 실행

  • 헌금안내 / 새가족 등록 페이지 추가 여부 (레퍼런스 3곳 모두 있음)
  • 주보 형식이 이미지 여러 장인지, PDF인지
  • 주보와 설교를 올릴 담당자는 몇 명인지

콘텐츠

  • 세부 교단 (합동 / 통합 등)

  • 예배 시간: 주일, 수요, 부서별
